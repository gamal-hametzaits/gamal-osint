# גמל OSINT 🔎

כלי OSINT עברי (RTL) לחיפוש נוכחות פומבית של שמות משתמש ושמות ברשת. מזינים שם משתמש או שם מלא, והכלי סורק **42 פלטפורמות** ומחזיר תמונה מסודרת: איפה נמצא, איפה לא, ואיפה לא ניתן לדעת.

**הכלי החי:** https://gamal-osint.gamal-hametzaits.workers.dev

## מה הוא עושה

- **סריקת שם משתמש** ב-42 פלטפורמות: קוד (GitHub, GitLab, npm, PyPI), קהילות (Reddit, Hacker News), רשתות חברתיות, פרופילים ועוד.
- **רמות ודאות מסומנות:** תוצאות מ-API מכונה מסומנות `verified`; אתרים שחוסמים סריקה מסומנים ביושר כ`unknown` — בלי ניחושים מומצאים.
- **חיפוש הקשר** לפי שם מלא.
- **הגבלת קצב** בסיסית לכל IP (12 בקשות בדקה, ברמת ה-isolate) כדי לשמור על התשתית החינמית.

## ארכיטקטורה

- **Cloudflare Worker** יחיד (`worker.js`) — מגיש את ה-UI ומבצע את הסריקות ישירות מה-edge, בלי מפתחות API ובלי שרת.
- `platforms.js` — הגדרות הפלטפורמות: שיטת בדיקה (`status` / `content` / `json-*`), חתימות זיהוי, וקישורי פרופיל.
- `html.js` — ממשק עברי RTL בקובץ יחיד, בלי build step.
- הכל על Free Tier, כמו שאר הפרויקטים של הגמל.

## פריסה (Deploy)

דרישות: Node.js 20+ וחשבון Cloudflare (חינמי).

1. `npm install`
2. יוצרים API token עם ההרשאה `Edit Cloudflare Workers` ומייצאים:
   `export CLOUDFLARE_API_TOKEN=<the-token>`
3. `npx wrangler deploy`

## הערות

- תוצאה של "נמצא" היא אינדיקציה, לא הוכחת זהות — שמות משתמש זהים אצל אנשים שונים הם דבר שכיח.
- חלק מהפלטפורמות (מסומנות `fragile`) חוסמות לעיתים בקשות משרתים; התוצאה תסומן בהתאם.
